# Python Expense Tracker

A command-line expense tracker built with Python for recording, managing, and analysing personal expenses.

## Features

- Add new expenses
- View recorded expenses
- Calculate total spending
- Delete expenses
- Analyse spending by category
- Store expense data permanently in JSON
- Validate user input
- Display amounts in Kenyan Shillings (KSh)

## Technologies

- Python 3
- JSON
- File handling
- Exception handling
